Real-time Bus Tracker

A transit-data exercise that plots bus locations on a map and refreshes their positions periodically.

PROJECT CONCEPT / JAVASCRIPT / APIS

Contribution
Developer
Context
MIT xPRO exercise
Period
2022

The idea

This project connects an external transit API to a map, turning location data into an interface that shows bus movement in Boston.

The approach

The application requests vehicle locations and updates map markers on a ten-second interval.

My contribution

  • Integrated a transit API with a browser map.
  • Updated marker positions from refreshed vehicle-location data.

What I learned

The exercise introduced API consumption, asynchronous updates, and location-based interfaces.
