# Circuit Works — RTL architecture portfolio

Four executable hardware studies exploring compute, data movement, and on-chip communication. SystemVerilog RTL, self-checking testbenches, independent Python models, structural lint, generic synthesis, and reproducible performance experiments are included.

| Project | Main architecture question | Start here |
| --- | --- | --- |
| **01 · RV32 cluster** | What preserves precise execution when four pipelines contend for memory? | [Project guide](projects/01_rv32_cluster/README.md) |
| **02 · INT8 systolic tile** | How do operand movement and fill/drain cost affect useful MAC utilization? | [Project guide](projects/02_systolic_int8/README.md) |
| **03 · Warp memory** | How do access patterns turn into transactions and replay cycles? | [Project guide](projects/03_warp_memory/README.md) |
| **04 · Mesh NoC** | What happens to latency under contention and downstream backpressure? | [Project guide](projects/04_mesh_noc/README.md) |

## Run the evidence

On Ubuntu 24.04 with Python 3.10 or newer:

```sh
sudo apt-get update
sudo apt-get install -y iverilog verilator yosys make python3
make test
make lint
make synth
make report
```

No proprietary simulator, Python packages, RISC-V compiler, GPU, FPGA board, or dataset download is required. [Setup and debugging](docs/getting-started.md) explains every target and tool override. `make test` regenerates vectors, simulates actual RTL, compares results, and fails on a mismatch. It does not merely run Python architectural models.

**Read the [measured report](docs/results.md)** for the checked-in evidence and its scope. Machine-readable results are in `results/*.json`; generic synthesis transcripts are included. The four suites contain 1,076 cases/operations in total. Counts describe the tested stimulus, not a coverage percentage or a proof of correctness.

## Scope

These are independent educational RTL implementations, developed with AI assistance. They are not NVIDIA designs, RISC-V compliance-certified platforms, production GPU implementations, or fabricated silicon. The collection deliberately distinguishes implemented behavior, tested behavior, architectural reasoning, and future work. No MHz, watts, silicon area, or TOPS claim is inferred from a generic synthesis cell count.

The source is MIT licensed. External specifications are cited where used; no third-party processor or accelerator RTL has been copied into the designs.
