PacMen

An interactive browser exercise that creates moving PacMan characters and keeps them inside the screen boundaries.

PROJECT CONCEPT / JAVASCRIPT / INTERACTION

Contribution
Developer
Context
MIT xPRO exercise
Period
2022

The idea

A hands-on exploration of browser animation, DOM manipulation, and boundary detection. Visitors can add characters and start their movement.

The approach

JavaScript updates each character’s position and reverses its direction when it reaches the edge of the available space.

My contribution

  • Created characters dynamically through button interactions.
  • Implemented position updates and edge-detection logic.

What I learned

A foundational exercise in making JavaScript state visible through an interactive interface.
