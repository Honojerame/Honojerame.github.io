Bus Ticket Management

A Java desktop application for bus, driver, passenger, and ticket-management workflows, built with a student team.

PROJECT CONCEPT / SOFTWARE ENGINEERING / JAVA

Contribution
Developer & Scrum Master
Context
ENMU / collaborative course project
Period
Spring 2025

The idea

This semester-long team project brings transport administration and passenger booking into one Java Swing application. Separate user roles organize the workflows for administrators, drivers, and passengers.

The approach

Object-oriented design separates responsibilities across the application. Swing provides the desktop interface, while file I/O supports persistent records.

My contribution

  • Designed and implemented Admin, Driver, and Passenger classes.
  • Built the TicketHistoryGUI and integrated file handling and login logic.
  • Served as Scrum Master during the project and supported team coordination.
  • Contributed to the project recognized as Best Project in CS234, Spring 2025.

What I learned

Working across class design, interface logic, persistence, and team delivery helped me connect software architecture with the needs of actual users.
