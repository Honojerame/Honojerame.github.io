AMHS FOUP Digital Twin

Robotics · Drives · Actuators · Embedded Controls

System

Semiconductor fab AMHS

Role

Controls & simulation engineer

Stack

Python · JavaScript · HTML/CSS

Built

2026

A dependency-free digital twin of 300 mm wafer FOUP movement through a semiconductor fab. A deterministic microcontroller-style state machine dispatches multiple overhead hoist vehicles between stockers and process tools.

The plant model includes acceleration-limited servo motion, position feedback, timed hoist actuators, target-crossing detection, transfer sequencing, safety interlocks, and E-stop recovery. A real-time browser HMI animates each vehicle and exposes live velocity, controller state, dispatch queue, throughput, speed controls, and fault injection.

Six automated tests and GitHub Actions CI verify delivery, telemetry, controller safety, and loaded-carrier fault recovery. The repository also contains systems, sequence, and state-machine drawings.
