Book Review Sentiment Classifier

A direct comparison of a TF–IDF logistic-regression baseline and a bidirectional LSTM for classifying book-review sentiment.

PROJECT CONCEPT / MACHINE LEARNING / NLP

Contribution
Model development & evaluation
Context
Machine Learning Foundations
Period
2025

The idea

I built two models to classify Amazon book reviews as positive or negative, using the same dataset to compare a simpler text-classification baseline with a neural approach.

The approach

The baseline represents text with TF–IDF and classifies it with logistic regression. The neural model tokenizes and pads sequences, then applies an embedding layer, a bidirectional LSTM, and a sigmoid output.

My contribution

  • Implemented and evaluated both approaches on book-review text.
  • Compared test accuracy instead of assuming the neural model would perform better.
  • Identified pretrained embeddings and regularization as potential areas for further experimentation.

What I learned

The baseline reached 80% test accuracy, while the initial LSTM with random embeddings reached 74.5%. The simpler model performed better in this experiment.
